# V2.2 繁體中文補丁安裝說明

> **安裝前務必自行備份完整遊戲資料夾及玩家存檔！**
> 自動備份僅涵蓋補丁變更的檔案，不取代完整備份。

**本補丁免費提供，僅供已合法持有原版遊戲的玩家使用。適用於 Steam 英文版《Zeus + Poseidon》。**

使用前請閱讀 [使用前必讀](使用前必讀.md)。

此包不含完整遊戲、修改器、語音包或存檔。請先安裝相容的英文 Zeus + Poseidon。

## 安裝

請先關閉遊戲，將完整遊戲資料夾及玩家存檔複製到另一個位置，再執行下列步驟。

1. 完整解壓縮，保留 `payload` 資料夾及所有同層檔案。
2. 關閉要安裝的遊戲。
3. 雙擊 `檢查相容性.cmd`（或 `Check.cmd`），貼上遊戲資料夾完整路徑；該資料夾必須含有 `zeus.exe`。
4. 檢查通過後，雙擊 `安裝漢化.cmd`（或 `Install.cmd`），輸入同一個路徑。
5. 顯示安裝完成後照常執行遊戲。

Windows 內建 PowerShell 即可執行，不需安裝 Python。若存取遭拒，確認對目標遊戲資料夾有寫入權限；必要時以系統管理員身分執行。

## 相容性

只接受清單中完全相符的原版檔案，或已完整套用本版的檔案。不接受原版與補丁混用、不明修改版本或舊版漢化。檢查會驗證全部差異資料，實際重建並核對 16 個輸出檔案；全部通過後才允許安裝。

## 備份與還原

**還原工具已隨包提供，必須保留本次安裝所建立的完整備份才能使用。** 它僅還原本補丁變更的 16 個檔案及暫停使用的已識別 .chn 資源，不會還原整個遊戲或其他工具的修改。

安裝前會在遊戲資料夾建立 `ZH-Patch-Backup-v2.2-時間` 並核對備份，請保留。

若有已識別的舊 `Zeus_Text.chn`、`Zeus_MM.chn`，會保留並改名為 `.ZH-v2.2-disabled`，避免遊戲優先讀入；未知版本會拒絕安裝。

還原時關閉遊戲，雙擊 `還原原版.cmd`（或 `Restore.cmd`），依序輸入遊戲資料夾與本次安裝建立的備份資料夾完整路徑。工具會核對來源、目前版本和備份，若後續檔案已被其他補丁修改，則拒絕覆蓋。

安裝及還原不改動存檔、音檔與個人設定。請勿只挑部分差異檔案使用，文字、字庫及主程式必須配套。
